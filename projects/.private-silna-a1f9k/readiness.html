Key Observations
Observed Pattern: Failures are not evenly distributed over time; they cluster around specific windows, which suggests episodic instability rather than constant low-level noise. Root causes also differ by provider-payor combination: some failure modes point to data-quality and extraction issues (for example, patient lookup mismatches and timeout-driven incomplete workflows), while others indicate broader platform and integration reliability problems (such as portal/network errors and authentication breakdowns). This means remediation should be combination-specific, not one global fix.
Production Risks

🔐 Credential Failures — 19

Stale credentials cause silent loops. Lock-outs can block entire queues.

Mitigation: Pre-validate login before each batch. Alert within 5 min of first auth failure. Secrets manager with rotation triggers.

👤 Patient Not Found — 17

Mismatched member ID or DOB from OCR. Risk: wrong patient or silently dropped authorization.

Mitigation: Patient match confidence score. If lookup = 0, route to human. Log search params for audit.

⏱️ Agent Timeout — 7 (UHC only)

Max 3-hour timeout on UHC portal. Risk: partial submissions left open.

Mitigation: Per-step timing. Checkpoint resumption. Human handoff alert at 2h.

📄 Document Upload — 4

Required docs fail to attach. PA without supporting docs will be denied.

Mitigation: Post-upload screenshot verify. Halt if doc count mismatches expected.

🔀 Delegated Auth — 5

Auth delegated to different insurer. Agent goes to wrong portal, risks duplicates.

Mitigation: Pre-flight delegation check in system prompt. Route or flag on detection.

🌐 Portal 403 — 7 (UHC)

Rate limiting or session expiry. Could escalate at higher volume.

Mitigation: Exponential backoff. Session keep-alive. Circuit-breaker on 3+ sequential 403s.
